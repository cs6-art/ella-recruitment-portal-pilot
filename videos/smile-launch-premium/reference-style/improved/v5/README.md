# Smile Recruitment Portal — V5

V5 refines the accepted V4 cut while keeping the pilot's real HR and candidate workflow.

## Build and render

```powershell
npm run build
npm run check
npm run render -- --quality delivery --output renders/smile-recruitment-portal-v5-final.mp4
```

The render helper uses FFmpeg/FFprobe from `PATH` or the standard Gyan.FFmpeg WinGet install. The source composition is generated by `scripts/build-smile-v5.mjs` into `index.html`.

## Files

- Final MP4: `renders/smile-recruitment-portal-v5-final.mp4`
- V4/V5 same-time comparison: `snapshots/v4-v5-compare/paired-overview.png`
- Encoded-output frame checks: `snapshots/v5-encoded-check/`
- Creative review and product claims: `CREATIVE_REVIEW.md`, `CLAIM_SOURCES.md`

The V5 MP4 retains the V4 music bed and adds scene-level volume automation and retimed interface cues. A separately generated Mureka track is available in ChatCut, but its browser download was not available to this local project renderer.
