# Smile promo — improved project

V3 final exports:

- `renders/smile-launch-improved.mp4` — landscape, 1920×1080.
- `renders/smile-launch-improved-vertical.mp4` — portrait, 1080×1920.
- `smile-launch-improved-poster.png` — final CTA poster.

The editable source is `scripts/build-smile-improved.mjs`, `index.html`, and `compositions/scene-0.html` through `scene-6.html`. The portrait source is in `vertical/` and is generated from the same scene script with a 1080×1920 canvas.

Run `npm run check` in each format directory before rendering. See `ITERATION_HISTORY.md`, `VIDEO_GENERATION_LESSONS.md`, `CREATIVE_STANDARDS.md`, `REFERENCE_COMPARISON.md`, and `BEFORE_AFTER_ANALYSIS.md` for the review and workflow constraints.
