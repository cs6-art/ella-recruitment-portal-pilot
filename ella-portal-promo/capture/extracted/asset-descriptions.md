# Asset inventory

- `assets/smile-recruitment-portal-logo.png` — existing Smile Recruitment Portal mark from the repository's `public/` directory. Used in the reconstructed app sidebar and campaign close. This is the only image asset in the film.
- `assets/ella-promo-score.wav` — locally synthesized original score created by `scripts/create-score.mjs`; no samples, provider calls, or third-party track.
- `assets/gsap.min.js` — local copy of GSAP 3.14.2 for deterministic, seekable animation.

No live site capture was made. The app's configured services were not started or contacted. The source repository includes `public/hero image.jpg`, but it is excluded because it contains a 94% score that has not been verified as an actual result. Product scenes are reconstructed from source page/component labels and styles, with visible illustrative/demo labels.
